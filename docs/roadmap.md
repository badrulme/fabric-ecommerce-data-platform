# Eight-module hands-on roadmap

| Module | What you will do | Proof of learning |
|---|---|---|
| 01 | Workspace, trial capacity, OneLake, Lakehouse | Explain Workspace vs Capacity and show Files/Tables |
| 02 | Generate synthetic CSVs; Copy using Data Factory | 5 CSVs in Files/raw and successful run |
| 03 | PySpark CSV to Bronze Delta tables | Bronze row counts and ingestion metadata |
| 04 | Clean and validate Silver data | Assertions for types, duplicates and relationships |
| 05 | Build dim and fact Delta tables | Star schema SQL query and correct revenue |
| 06 | Semantic model and Power BI | Dashboard with reconciled KPIs |
| 07 | Pipeline orchestration and monitoring | End-to-end rerun and failure recovery demo |
| 08 | Security, cost, governance, Git/CI and client Q&A | Architecture walkthrough and operations checklist |

**Teaching loop:** explain concept briefly → do the practical task → verify actual output → answer recall questions → discuss production tradeoffs.

Never claim a module is complete until its evidence has been observed.
